# Testudo Forge Homebrew tap

Homebrew casks for apps from [Testudo Forge LLC](https://testudoforge.com).

## Install

```sh
brew install --cask testudo-forge-llc/tap/tempmonitor
```

That taps this repository and installs the app in one step.

## Casks

| Cask | App | Requires |
| --- | --- | --- |
| `tempmonitor` | [TempMonitor](https://testudoforge.com/tempmonitor): macOS menu bar monitor for CPU temperature, GPU temperature and fan speeds | Apple Silicon, macOS Sonoma or later |

The app is signed with a Developer ID and notarised by Apple.

## Maintenance

The cask files here are copied byte for byte from the TempMonitor project, where they are maintained alongside the
app. Please do not edit them in this repository.
